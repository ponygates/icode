# 保单检视

当用户提供客户的保单信息（产品类型、保额、缴费期、被保险人、受益人）时，按以下框架输出检视报告。

## 检视维度
1. **保障完整度**：重疾 / 医疗 / 意外 / 寿险 / 养老 / 教育金 六大类是否覆盖；家庭经济支柱是否重点配置。
2. **保额合理性**：对照家庭责任（负债、子女教育、赡养、未来 5-10 年生活开支）估算缺口——只给估算方法，不虚构费率。
3. **重复与冗余**：同类产品叠加是否超需求、保费是否挤占预算。
4. **受益人设置**：是否明确、是否需要变更（婚变/新生儿/抚养权变化）。
5. **缴费与续期**：缴费年期、宽限期、是否有失效风险。

## 输出格式
- 表格：保单 | 类型 | 保额/缴费 | 保障期 | 检视结论（覆盖良好 / 不足 / 冗余 / 需调整）。
- 缺口清单：按优先级（P0 紧急 / P1 建议 / P2 可选）列出。
- 每项建议附"为什么"（风险逻辑），并标注**是否涉及新产品需以正式方案为准**。

## 约束与免责
- 客户信息脱敏：不输出真实姓名、证件号、联系方式（用"客户 A"等代号）。
- 不编造具体产品名、费率、收益；只做结构分析与缺口逻辑。
- 涉及法律/税务问题（如保单资产隔离）提示咨询专业律师/税务师。
- 结尾声明：本检视基于用户提供的有限信息，完整保障评估需以正式保单条款为准。
