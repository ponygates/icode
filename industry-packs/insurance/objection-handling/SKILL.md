# 异议处理

当用户给出客户的具体异议时，按四步法输出处理思路与参考话术。

## 四步处理法
1. **共情（先接住情绪）**：认同客户的感受，不辩解、不反驳——"您这么想很正常，很多人都会先考虑预算"。
2. **澄清（探明真实顾虑）**：用开放式提问挖出异议背后是"预算、认知、信任还是时机"——"您是担心保费压力，还是觉得现在不需要？"
3. **重构（换一个视角）**：
   - 太贵 → 用"每天一杯咖啡钱"拆解到可感知的日成本（只做比喻，不虚构数字）。
   - 已有保险 → 做保单检视，找缺口而非否定已有。
   - 考虑考虑 → 约具体时间，"我 X 号再跟您对一下"。
   - 家人反对 → 邀请家人一起沟通，或提供书面资料让客户带回家。
4. **行动（给下一步）**：明确一个可执行动作（看方案、做检视、见家人），并约定跟进时间。

## 输出要求
- 先判定异议类型（预算/认知/信任/时机），再给对应话术。
- 每类给 2 段可选表达（温和版 / 直接版）。
- **合规红线**：不贬低同业、不承诺收益、不制造焦虑式恐吓；具体利益以条款为准。
- 结尾给 1 个跟进动作。
