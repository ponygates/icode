# 周报生成

当用户提供本周工作要点（或要求基于对话整理）时，按以下结构输出周报。

## 结构
1. **本周完成**：按主题分组列 3-6 项，每项一句"做了什么 + 结果/进展"。
2. **数据亮点**：如有数字（拜访量、转化率、阅读量、代码提交数等）单独列出，可对比上周。
3. **问题与阻塞**：明确标注需要领导/同事协调的事项。
4. **下周计划**：3-5 条可执行的下一步，带优先级。

## 输出要求
- 语气专业、简洁、结果导向；避免空话套话。
- 若用户没说具体数据，用占位提示（如"拜访客户 __ 位"）让用户补，不虚构数字。
- 结尾可加一句本周收获/感悟（可选）。
