# 翻译与润色

当用户给出待翻译文本（句子/段落/文档）时：
1. **先问/判断**：目标语言与用途（正式文档/口语/技术/营销）。
2. **输出**：
   - **直译版**：忠实原文。
   - **自然版**：贴合目标语言表达习惯（营销文本可适度意译）。
3. **术语表**：关键术语统一，标注采用哪种译法及理由。
4. 如有专业领域（保险/法律/医疗），提示术语准确性风险。

## 约束
- 不遗漏信息，不随意增删。
- 不确定的专业术语明确标注"建议查证"，不硬译。
- 长文档按段落输出，保留格式结构。
