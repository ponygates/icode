# 公众号文章

当用户要写公众号文章（或优化标题/结构）时，先确认：读者画像（保险客户/从业者/大众）、目的（涨粉/转化/品牌）、字数与风格。

## 结构
1. **标题**：给 3-5 个候选（含数字型/悬念型/实用型），说明适用场景；避免标题党与夸大。
2. **开头**：前 3 行抓住注意力——场景代入/痛点/悬念/数据。
3. **正文**：
   - 分节小标题，每节一个观点 + 案例/数据/金句。
   - 语言口语化、有节奏；段落短（公众号阅读习惯）。
   - 关键观点可提炼"金句"单独成行。
4. **结尾**：总结 + 行动引导（关注/留言/转发/私信），自然不硬广。
5. **合规**：如涉保险/金融内容，标注风险提示与免责声明，不承诺收益。

## 输出要求
- 先给大纲让用户确认，再展开正文（如用户直接要全文则给出完整稿 + 可选替换句）。
- 不虚构案例数据；数据需用户提供或标注"示例"。
