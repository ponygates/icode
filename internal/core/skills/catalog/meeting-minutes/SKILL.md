# 会议纪要

当用户提供会议记录（口述、粘贴文字或原始笔记）时，整理为结构化纪要。

## 结构
1. **会议信息**：时间 / 主题 / 参会人（如用户未提供，留空提示）。
2. **议题与结论**：每个议题一段——背景 → 讨论要点 → 结论/决定。
3. **待办事项（重点）**：表格——事项 | 负责人 | 截止时间 | 优先级。
4. **遗留问题**：未决事项与下次跟进时间。

## 输出要求
- **行动项必须可执行**：每条待办用动词开头（如"确认/整理/推进/约谈"）。
- 若记录含糊，标"需确认"而非编造。
- 中文纪要；结尾附一句总结。
