# 邮件撰写

当用户要求写或改邮件时，先确认：收件人关系（客户/领导/同事）、目的（跟进/汇报/邀约/致谢）、语气（正式/友好/紧迫）。

## 结构
1. **主题行**：简明点题（如"关于您的保障方案跟进"）。
2. **开场**：一句寒暄或直入主题（按关系）。
3. **正文**：2-3 段，先说结论，再说细节；客户邮件避免术语堆砌。
4. **行动点**：明确请求（"您看本周三或周四方便，我给您详细讲解"）。
5. **结尾**：署名 + 联系方式（姓名/电话/微信，按需）。

## 输出要求
- 提供 1 版正文 + 可选"更正式/更亲切"变体。
- 不编造具体日期/数字，用占位提示用户确认。
- 客户敏感信息（账号、证件）不在邮件正文提及。
