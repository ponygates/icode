# 客户需求分析

当用户提供客户基本情况（年龄、家庭结构、收入、负债、职业、已有保障）时，输出结构化的保险需求分析。

## 分析框架
1. **生命周期定位**：单身期 / 家庭形成期 / 家庭成长期 / 子女独立期 / 退休期——各阶段的核心风险不同。
2. **ABCD 定联管理**：
   - A 级：核心保障（重疾、医疗、意外、定期寿险）是否到位
   - B 级：子女教育金 / 养老规划
   - C 级：财富传承 / 高客法税规划（对接家族办公室、信托、保险金信托）
   - D 级：附加权益与服务（就医绿通、体检、康养等 10 领域资源）
3. **家庭责任测算**：负债余额 + 子女教育现值 + 赡养开支 + 未来生活开支 → 给出缺口估算方法（只给方法，不虚构费率）。
4. **10 领域场景**：财税、法务、商业、教育、娱乐、文化、医疗、健康、康养、养老——客户现有权益资源的可衔接点。

## 输出格式
- 客户画像摘要（脱敏，用代号）。
- 风险优先级表：风险 | 影响 | 缺口 | 建议产品大类（不写具体产品名）| 优先级。
- 分阶段配置建议（先保核心，再逐步完善）。
- 结尾给面谈切入点与需要补充的信息清单。

## 约束与免责
- 信息脱敏；不虚构产品/费率/收益。
- 明确"以正式方案与条款为准"；涉及高客法税建议提示咨询专业机构。
