# iCode 对标差距分析报告（2026-08-11）

> 对标对象：**CLI / 简易 UI** → claude code、opencode、reasonix；**桌面版** → reasonix 桌面、workbuddy
> 结论先行：iCode 在「能力广度」和「Token 节省」上已经领先四个对标产品；差距集中在「体验精致度」和「生态（市场/自动化）」两个方向。

---

## 一、现状盘点（已验证）

| 维度 | iCode 现状 | 对标结论 |
|---|---|---|
| 斜杠命令 | **72 个**（/undo /share /cost 面板 /output-style /add-dir /update /vim /statusline /bug /pr_comments /release-notes…） | ✅ 远超 claude code（~30）、opencode（~25） |
| Token 节省 | Cache-First Loop + 5 层压缩 + `/token` 节省报告 + 桌面 Analytics | ✅ 四家均无此体系，核心卖点 |
| 多模型聚合 | 10+ 国内 + OpenRouter/Anthropic/OpenAI 等 50+ 提供商 | ✅ 领先 |
| 中文原生 | zh-CN/zh-TW/en 三语 i18n（CLI + 桌面） | ✅ reasonix 之外均无 |
| 会话管理 | 桌面多标签页（openTabIds）、CLI /sessions /resume、简易 UI 会话下拉 | ✅ 持平 |
| 技能/Teams/Agents/Hooks | 全套 + 技能市场 API + 设置页前端入口 | ✅ 对标 workbuddy 技能体系 |
| 桌面设计系统 | Reasonix 风格（发丝边框/无阴影/大标题/快捷键面板 `?`） | ✅ 持平 |
| 启动稳定性 | WebView2 僵尸清理 + 数据目录修复 + 单实例锁 + 线程亲和 + ephemeral 兜底 + 阶段计时日志 | ✅ 近期加固 |

## 二、CLI 端差距（对标 claude code / opencode / reasonix）

### 2.1 值得补（高价值，中等工作量）

| # | 差距 | 对标源 | 具体建议 |
|---|---|---|---|
| C1 | **彩色 git diff 渲染** | claude code | `/diff` 输出改为行内 ANSI 彩色（+绿 / -红 / 块头青），当前是纯文本 |
| C2 | **tool 调用折叠卡片** | opencode | 工具执行显示为可折叠块（状态行 + 内容，`+`/`-` 展开收起），当前是长文本块 |
| C3 | **上下文条可视化** | claude code | 状态栏/输入框上方加 `context: NN% ▓▓░░` 实时条（已有 contextBar 但只在特定位置显示，未放输入区上方） |
| C4 | **plan/act 审批中心** | claude code | 权限请求弹出时提供「批准 / 拒绝 / 改请求」三键选择（当前面板有，但交互层级可再对齐） |
| C5 | **代码块语法高亮** | reasonix TUI | Markdown 渲染的代码块按语言着色（CLI 终端内），当前是单色 |

### 2.2 可选补（低价值/高成本，建议暂缓）

| # | 差距 | 说明 |
|---|---|---|
| C6 | 真正的多工作区 `/add-dir` | 当前是「上下文注入」；真正实现需工具路径沙箱 + 会话级白名单，改动大 |
| C7 | 多会话并行 | 桌面已有标签页，CLI 单会话为主；并行会显著增加复杂度 |
| C8 | 命令智能推荐 | claude code 基于历史推荐命令；iCode 为前缀匹配，收益有限 |

## 四、桌面端差距（对标 reasonix 桌面 / workbuddy）

### 4.1 高价值

| # | 差距 | 对标源 | 建议 |
|---|---|---|---|
| D1 | **定时任务 / 自动化** | workbuddy | 路线图已立项的大功能：调度器 + 持久化 + 执行历史。workbuddy 的杀手锏之一 |
| D2 | **MCP 测试 UI** | workbuddy | 后端有 `/api/mcp/test`，前端没有可视化测试入口（连接测试按钮 + 结果展示） |

### 4.2 中价值

| # | 差距 | 建议 |
|---|---|---|
| D5 | 知识库/资料库集成 | workbuddy 的资料库（文档/表格导入）是差异化功能；iCode 无 |
