# 司马君新闻早报 · 整理模板

> 目标群：企业微信群（成员可为个人微信用户）
> 来源群：你的个人微信群（手动转发原文给我，我来整理）
> 频率：每天 1 次，10-30 条

## 成品样式（照此格式输出）

```
【司马君新闻早报】
<年份>年 <月>月<日>日，<星期X>，农历<X月X>，<城市>，<天气符号><天气>，<温度区间>℃，湿度<X>%，体感<X>℃，风速<X>km/h，祝<XX>，幸福生活！

1、<来源1>：<新闻1>；
2、<来源2>：<新闻2>；
...
N、<来源N>：<新闻N>；

🍒【厨房神奇小妙招】
<标题>
<内容>

【司马君微语】
<一句话收尾>✨
```

## 模板元素说明

| 元素 | 要求 |
|------|------|
| 报头 | 日期、农历、城市、天气、温度、湿度、体感、风速、祝福语（照例更新当日真实数据） |
| 新闻条目 | 每条 1 行：`序号、来源：内容；`，来源如「中央气象台」「央行」「教育部」「德媒」「美媒」「俄媒」「马媒」「法媒」等 |
| 新闻条数 | 10-30 条，覆盖国内外时政/财经/科技/民生/国际 |
| 厨房小妙招 | 每日换一个生活小技巧，格式：标题 + 一段做法 |
| 微语 | 一句温和的收尾，带 ✨ |

## 工作流

1. 用户把源群新闻原文（文字/链接/截图）发给我
2. 我按以上模板整理成完整成品
3. 调用 `send_wecom_news` 工具发送到目标企微群
4. （可选）把成品存档到 `.wecom-news/archive/` 目录

## 配置

- webhook 地址：`.wecom-news/config.json` 中的 `webhook` 字段
